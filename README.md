# 교육정보부 노트북 대여 관리

교사들이 휴대폰이나 PC로 노트북 1~15번을 직접 대여·반납하는 웹앱입니다.
화면은 GitHub Pages에서 열고, 데이터는 구글 시트에 저장됩니다.

```
index.html, style.css, script.js   → GitHub Pages (화면)
apps-script/Code.gs                → 구글 시트의 Apps Script (저장소)
```

## 처음 설치하기

### 1. 구글 시트 만들기
1. [sheets.new](https://sheets.new)에서 새 스프레드시트를 만들고 이름을 정합니다. (예: 노트북 대여 관리)
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 들어 있는 코드를 모두 지우고 `apps-script/Code.gs`의 내용을 붙여 넣은 뒤 저장합니다.

### 2. 시트 초기화 (한 번만)
1. Apps Script 편집기 위쪽의 함수 선택 칸에서 `setup`을 고르고 **실행**을 누릅니다.
2. 권한 요청 창이 뜨면 본인 계정을 선택하고 허용합니다.
   "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다.
3. 시트에 **현황**, **기록** 탭이 생기고, 현황에 노트북 1~15번이 "대여 가능"으로 채워지면 성공입니다.

> 주의: `setup`을 다시 실행하면 **현황** 탭이 모두 "대여 가능"으로 초기화됩니다. **기록** 탭은 지워지지 않습니다.

### 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(톱니바퀴)에서 **웹 앱**을 고릅니다.
3. 다음처럼 설정하고 **배포**를 누릅니다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> 학교 Google Workspace 계정에서 "모든 사용자"가 보이지 않으면 관리자가 외부 공유를 막아 둔 것입니다.
> 이 경우 개인 Gmail 계정으로 1~3단계를 진행하세요.

### 4. 주소 연결 후 GitHub에 올리기
1. `script.js` 맨 위의 `API_URL` 값을 복사한 웹 앱 URL로 바꿉니다.
   ```js
   const API_URL = "https://script.google.com/macros/s/.../exec";
   ```
2. 저장소에 커밋하고 푸시하면 GitHub Pages 주소에서 바로 사용할 수 있습니다.

## 사용 중 알아 둘 점

- **갱신 주기**: 다른 선생님이 바꾼 내용은 15초마다, 또는 앱 화면으로 돌아올 때 반영됩니다. 내가 대여·반납하면 즉시 반영됩니다.
- **동시 대여 방지**: 두 사람이 같은 노트북을 동시에 빌리면 먼저 저장된 한 명만 대여되고, 나머지 사람에게는 안내 문구가 나옵니다.
- **담당자 확인**: 구글 시트의 **현황**과 **기록** 탭에서 바로 확인하고, 필터나 인쇄도 할 수 있습니다.
- **시트를 직접 고칠 때**: 현황 탭의 행 순서(2행 = 1번 … 16행 = 15번)는 바꾸지 마세요. 상태 칸에는 `대여 중` 또는 `대여 가능`만 적어야 합니다.
- **Code.gs를 수정했을 때**: **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 URL은 그대로 유지됩니다.
- **보안**: 웹 앱 주소를 아는 사람은 누구나 대여·반납할 수 있습니다. 교내 안내문이나 메신저로만 주소를 공유하세요.
- **개인정보**: 교사 이름과 반납 예정일만 저장합니다.
